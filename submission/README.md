# Submission package

Current pitch deck: [`TallyGuard_Tameion_Pitch_v9.pptx`](TallyGuard_Tameion_Pitch_v9.pptx)

The ten-slide deck is generated by `build_pitch_deck.mjs` with editable native
text, shapes, and the decision matrix. It is an earlier product snapshot;
current check counts and live behavior should be taken from the repository and
demo film. The deck includes a standalone evidence-packet verifier, isolated Testnet wallet
pair setup, eight-check real-HTTP deployment acceptance, responsive evidence,
and genuine-pilot claim boundary.

The public repository, live simulation site, and real Arc Testnet acceptance
are complete and documented. No external customer pilot has been verified;
the 50 automated workflows and 40 confirmed Testnet transfers are engineering
evidence, not human-user traction. The owner-approved 3:12 film is retained,
with a separately reviewed 2:59 cut for the official video field.

Submission working files:

- `FINAL_SUBMISSION_COPY.md`: canonical form answers with explicit pending fields
- `TAMEION_FORM_FILL_GUIDE.md`: field-by-field owner guide for the actual form
- `DEMO_RUNBOOK.md`: timed product-first walkthrough for a sub-three-minute video
- `RELEASE_CHECKLIST.md`: repository, deployment, Testnet, pilot, media, and form gates

Run `tallyguard-release-audit --output artifacts/release-audit.json` at any time
to hash the local package and list the remaining external evidence without
mistaking a placeholder for a completed submission. `--require-complete`
also requires a genuine pilot report, which is not an official form prerequisite;
do not delay event submission or invent usage merely to make that optional gate
green.

After deployment, run `tallyguard-deployment-smoke --base-url <LIVE_URL>
--output artifacts/remote-deployment-smoke.json`. It exercises the public judge
workflow from outside the host, refuses funds-moving or Mainnet readiness, and
revokes the temporary role sessions it creates.

If the optional controlled Mainnet proof is completed, add
`--mainnet-acceptance-artifact artifacts/mainnet-acceptance/<run>.json`. The audit
accepts it only when it is capped at 0.01 USDC, role-separated, bound to the
payment intent, Circle-backed, Arc-Mainnet-confirmed, and idempotently replayed;
synthetic fake-adapter reports fail this optional check.
